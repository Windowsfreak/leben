# Leben App LLM Admin API Specification (Go Backend)

> Protected administrative APIs for automated AI tools, content CRUD, AI translations, task management, image & asset operations, and MCP protocol.

## Authentication
Admin operations require authentication via a token acquired through `POST /api/admin/login` or using the configured secret admin token / password.

Authentication headers accepted on protected requests:
- `Authorization: Bearer <admin_token>`
- `X-Admin-Token: <admin_token>`
- `X-Admin-Password: <admin_password>`

---

## 1. Auth & Status (`/api/admin/login`)

### `POST /api/admin/login`
- **Req**: JSON `{"password": "<password>"}`
- **Res**: `{"status": "success", "message": "Login successful.", "token": "<admin_token>"}`

---

## 2. Tile Management & Vector Operations (`/api/admin/tiles`)

### `GET /api/admin/tiles`
- **Req**: Headers with admin token
- **Res**: `{"status": "success", "tiles": [...]}`
- Returns full list of all tiles in database including secret and invisible tiles.

### `POST /api/admin/tiles` or `PUT /api/admin/tiles`
- **Req**: JSON object (`Content-Type: application/json`):
  - `id` (int, optional for update)
  - `name` (str, required)
  - `language` ("de"|"en")
  - `title` (str, required)
  - `summary` (str)
  - `html_teaser` (str)
  - `content_file` (str)
  - `tags` (comma-delimited string, e.g. `"leben, design, zukunft"`)
  - `type` ("doc"|"link")
  - `link` (str)
  - `secret` (str)
  - `accent_color` (hex)
  - `background` (str)
  - `visible` (bool)
  - `sort_order` (int)
- **Res**: `{"status": "success", "message": "Tile saved successfully.", "tile": object}`

### `DELETE /api/admin/tile/:id` (or `/api/admin/tiles/:id`)
- **Req**: Tile ID path parameter
- **Res**: `{"status": "success", "message": "Tile deleted."}`

### `POST /api/admin/tile/:id/toggle-visibility`
- **Req**: Tile ID path parameter
- **Res**: `{"status": "success", "message": "Tile visibility toggled."}`

### `POST /api/admin/tile/:id/clone`
- **Req**: Tile ID path parameter
- **Res**: `{"status": "success", "message": "Tile cloned successfully.", "clone_name": string}`

### `POST /api/admin/tile/:name/translate` (or `/api/admin/tile/:id/translate`)
- **Req**: JSON `{"name": string, "target_lang": string}` or query parameter `target_lang` ("de"|"en"|"all", default "all")
- **Res**: `{"status": "success", "message": "Translation task started for card '...'", "task": {"id": string, "type": string, "status": string, ...}}`
- Triggers asynchronous translation task in the background.

### `POST /api/admin/tiles/refresh-vectors`
- **Res**: `{"status": "success", "message": "Vectors refreshed successfully for N tiles."}`

## 3. Background Task Management (`/api/admin/tasks`)

### `GET /api/admin/tasks`
- **Res**: `{"status": "success", "tasks": [{"id": string, "type": string, "target": string, "status": string, "error": string, "created_at": string, "updated_at": string}]}`

### `POST /api/admin/tasks/:id/cancel`
- **Req**: Task ID path parameter
- **Res**: `{"status": "success", "message": "Task '<id>' cancelled successfully."}`

---

## 4. Content & LLM Helper APIs (`/api/admin/content`)

### `GET /api/admin/content/:file`
- **Req**: Filename path parameter (e.g. `finance_de.html`)
- **Res**: `{"status": "success", "content": string, "mtime": int64}`

### `POST /api/admin/content/:file`
- **Req**: JSON `{"content": string, "expected_mtime": int64}`
- **Res**: `{"status": "success", "message": "File saved successfully.", "mtime": int64}`

### `POST /api/admin/content-suggest-meta`
- **Req**: JSON `{"name": string, "title": string, "content_file": string, "html_teaser": string}`
- **Res**: `{"status": "success", "data": {"summary": string, "tags": string}}`

### `POST /api/admin/content-edit-html`
- **Req**: JSON `{"prompt": string instruction, "html_teaser": string}`
- **Res**: `{"status": "success", "html_teaser": string}`

---

## 5. Image & Asset Operations (`/api/admin/images`, `/api/admin/assets`)

### `GET /api/admin/images`
- **Res**: `{"status": "success", "images": [{"name": string, "url": string, "size": int64, "mtime": int64}], "files": [...]}`

### `POST /api/admin/images/upload`
- **Req**: `multipart/form-data` with `image` or `file`
- **Res**: `{"status": "success", "message": "File uploaded successfully.", "name": string, "image": {"name": string, "url": string}}`

### `POST /api/admin/images/rename`
- **Req**: JSON `{"old_name": string, "new_name": string}`
- **Res**: `{"status": "success", "message": "File renamed successfully."}`

### `DELETE /api/admin/images/:name`
- **Req**: Image filename path parameter
- **Res**: `{"status": "success", "message": "File deleted."}`

### `GET /api/admin/assets`
- **Res**: `{"status": "success", "files": [{"name": string, "size": int64, "mtime": int64}]}`

### `POST /api/admin/assets/upload`
- **Req**: `multipart/form-data` with `file`
- **Res**: `{"status": "success", "message": "File uploaded successfully.", "name": string}`

### `POST /api/admin/assets/rename`
- **Req**: JSON `{"old_name": string, "new_name": string}`
- **Res**: `{"status": "success", "message": "File renamed successfully."}`

### `DELETE /api/admin/assets/:name`
- **Req**: Asset filename path parameter
- **Res**: `{"status": "success", "message": "File deleted."}`

---

## 6. Model Context Protocol (MCP Server Endpoint `/mcp`)

### `GET /mcp`
- Standard MCP SSE (Server-Sent Events) endpoint or JSON-RPC message endpoint.

### `POST /mcp`
- HTTP JSON-RPC 2.0 endpoint for MCP client tool execution (`search_tiles`, `get_similar_tiles`, `get_tile`, `translate_tile`, `get_task_status`, `cancel_task`, `save_content_file`).
